# P9 — 3D map + operator UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user's standing choice: inline execution, one fresh reviewer at the end). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn on the 2D / 3D switch on the operations and mission maps (terrain, a true-altitude path, vehicles and waypoints floated to their altitude) and ship the ten operator improvements the user approved on 2026-10-19 ("改善案は進めて").

**Architecture:** 3D = MapLibre terrain from a Terrarium DEM (`raster-dem`) plus one custom WebGL layer (`AirPathLayer`, ported from the prototype) that draws altitude polylines and vertical posts; DOM markers are shifted to their altitude by a projection helper. The DEM URL is a server setting so an offline site can serve its own tiles. Operator UX lives in the commands / detail / vehicles / log features; no server change except the DEM URL.

**Tech Stack:** React 19 + MapLibre GL 5.24 (`CustomLayerInterface`, `render(gl, {modelViewProjectionMatrix})`), Vitest + jsdom, Playwright; Rust axum for the one setting.

**Spec:** the user's requests of 2026-10-19 (P8 request 1 "2D/3D それぞれに合わせて"; "3D地図着手"; the ten proposals in the reply of 2026-10-19 accepted with "改善案は進めて"), the Glass prototype `design_base/project/RGCS Prototype Glass.dc.html` (3D: `AirPathLayer`, `applyMapMode`, `updateVehicleAir`, `floatMarkers`, `updateMissionAir`; screenshots `glass_ops_3d_follow.png`, `glass_mission_3d.png`), memory note "RGCS mission UI conventions" (3D rules).

## Global Constraints

- Design is binding: copy prototype class names (`seg onmap float map-r top1`, `.lens`, `g-ctl`, …); never hand-edit `prototype.css`; new styles go to `app.css`.
- 3D toggle: `pitch 60`, `bearing -25` on entering 3D, `pitch 0 bearing 0` on leaving, `duration 900`; `map.stop()` + `setTerrain()` BEFORE `easeTo()`; `maxPitch 70`.
- Terrain: Terrarium encoding, `tileSize 256`, `maxzoom 15`, `exaggeration 1`; hillshade off (2D look unchanged).
- Colours: `CYAN #9cc9ff`, `AMBER #f2b544` (selected), `ALT_HI #d8a8ff`, `POST_COLOR #bfe0ff`, casing tint `rgb(0.02,0.19,0.23)`; path core 4 px, casing +3 px, posts 2 px (+2 casing).
- Vehicle altitude in 3D = DEM elevation at its home (HOME_POSITION, else mission home, else first track point) + `alt_rel` (prototype rule; `alt_msl` is NOT used — SITL's MSL is unrelated to the DEM).
- Mission item altitude in 3D: Rel → home ground + alt; Abs → alt; Ter → ground at the item + alt.
- GL state is touched only inside `render()`; uploads are deferred to it; own VAO (WebGL2 `createVertexArray`).
- Default DEM URL `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png`; `terrain_tiles = ""` in config.toml disables 3D (button disabled, title says why).
- 3D mode is per browser: localStorage `rgcs.mapMode` (`'2d' | '3d'`), shared by ops and mission maps.
- No `window.confirm`; immutable state; files ≤ 400 lines (800 max); functions < 50 lines; single quotes, no semicolons, hand-formatted (no prettier).
- Long-press for in-flight DISARM: 1500 ms hold.
- Fleet commands go to every vehicle whose link is not `lost`; each sends with its own confirm token.
- Japanese and English strings for everything new (`shared/i18n/opsTools.ts` or a new `ops3d.ts` part).

## Review Focus

- A vehicle with no position / no home / DEM tile not yet loaded in 3D: no NaN vertices, the marker stays at ground until the DEM arrives, then floats (test in `air.test.ts`).
- Switching 2D ↔ 3D while following a vehicle, and switching while a drag is in progress: no exception, follow keeps working (live check in Task 4).
- Pressing Enter in the confirm dialog while focus is in a text input elsewhere must not execute a command (only the dialog's own key handler while it is open; test in ConfirmDialog.test).
- Fleet command when one vehicle refuses (409 / timeout): the others still get theirs and each result is logged per vehicle (test in fleet.test).
- Right-click on the map while the guided modal is already open for another vehicle: the target vehicle becomes the selected one, not the modal's old vehicle (test in Shell-level guided test).
