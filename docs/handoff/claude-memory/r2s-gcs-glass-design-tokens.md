`design_base/project/RGCS Prototype Glass.dc.html` is the user-approved visual direction for RGCS (same script as `RGCS Prototype.dc.html`, restyled). Decisions, all confirmed by the user on 2026-10-16:
- Look: "simple, refined, a little liquid glass". Near-achromatic frosted panels over the live map; colour carries meaning only: ice blue `#9cc9ff` = interactive/selected (`--accent`, dark text `#0b1b2e` on it), amber `#f2b544` = caution/selected vehicle, red `#ff6961` (`--rec #e5484d` for REC pills) = danger, green `#5fd39b` = healthy/ROI. Altitude gradient ice → lilac `#d8a8ff`. Base `#11161e`; text `#f2f5f8 / #b3bfcc / #8a97a5 / #687582`. Neon cyan `#00e5ff` and navy `#0b1626` surfaces are retired.
- Glass recipe is one class `.g` (`rgba(20,26,34,.56)` + `backdrop-filter: blur(22px) saturate(1.35)`, 1px `rgba(255,255,255,.09)` border, inset top highlight, radius 18) with `.g-strong` for modals and `.g-ctl` for small map controls (radius 12). Non-map views (video, maintenance) use matte `.surface` panels over a faint two-blob `.aurora` so the glass still has something to blur.
- Type: IBM Plex Sans JP 300/400/500/600 (Noto Sans JP fallback), IBM Plex Mono only for MAV_CMD / ArduPilot parameter identifiers; base 13px, telemetry numbers 22px weight 300 with small units, tabular-nums everywhere numeric.
- Layout: header is a floating glass bar (top 10px, 52px); `main.stage` is the full window, the map `inset:0`, panels are `position:absolute` floats (aside 296px / right 372px; mission 320 / 360; collapsed list rail 60px) driven by CSS vars `--aside-w/--right-w/--top` set from stage classes (`mission`, `rail`, `noright`, `video`, `maint`, `elev`). Map overlays use `.map-l/.map-r/.map-c` offsets. The footer log is a centred pill at the bottom; MapLibre scale/attribution are lifted to `bottom:60px` (272px while the elevation sheet is open, which itself sits at `bottom:60px`).
- The "liquid" moment is the sliding lens of segmented controls (`.seg .lens` with `transform:translateX(n*100%)` from vals `navLens`, `mapLens`, `toolLens`, `langLens`, `maintLens`), disabled under prefers-reduced-motion.
- Script changes vs the original: colour constants, class-name vals instead of colour vals (`rowCls`, `tileCls`, `*Cls`), `stageCls` replaces `bodyCols`, and `syncPadding()` calls `map.setPadding({top:72,left,right,bottom})` from the panel state so follow/easeTo stay centred in the visible map (verified: follow offset 1px). MapLibre compact attribution is forced closed unless hovered via CSS on `.maplibregl-compact-show`.
- Verified 2026-10-16 with CDP-driven Chrome: all 17 screens render, console clean apart from the inherent `{{ }}` number-input warnings, 3D rotate/pan 60 fps with backdrop-filter (same as the original). Build was a scratch `build.js` (head + 3 template parts + patched script); the scratchpad is ephemeral, so the committed HTML is the source of truth.

- Camera integration (2026-10-16, commit after `29d3905`): `CAM_CAPS[kind]` (mt11 / mavlink) gates every camera control with `sc-if`; missing capabilities are hidden, never disabled. Detail panel gets a `.cam-strip` (rec / photo / zoom / RGB·IR·2画面 seg / gear) + `.cam-status` hairline-separated status row; maximized video is the cockpit: `.cam-bar` pill under the video (rec, photo, log-scale zoom range 1–zoomMax, video-mode seg, gimbal-mode seg, center, AI track toggle, gear) + ROI `.chips` row, `.trk` tracking box (accent dashed → ok solid → caution), `.tmark` hot/cold thermal markers, IR look = CSS filter on `.feed.ir`, right column = mini-map (centres on the watched vehicle, `sight` dashed ok-green line from vehicle along hdg−yaw to the active ROI, `.rg-roi` preset markers) + `.cam-card` with `.cam-dial` (yaw/pitch dot) and `.kv` rows. Camera settings = `modal:'camera'` g-strong sheet (`map-r top2`, 440px) with `.seg.n4` tabs 接続/操作/ROI/映像 editing `state.camDraft`; Save applies to `vehicle.camera`, `this.roiPresets`, `this.gimbalInput`. Login view (`view:'login'`, `.login .card`, mock admin/admin) hides header/footer via `sc-if authed`; header user button opens `.pop` with logout. `window.__rgcs` is now set in componentDidMount so the harness can log in (`setState({loginUser:'admin',loginPass:'admin'}); login()`).

**Why:** the user asked for a simpler, more refined design with some liquid glass, as a new file; these tokens are meant to become the Rust/Tauri (React + TS) theme.

**How to apply:** edit the Glass file, not the original, for further design work; keep the token names and the stage/float layout. See [[r2s-gcs-mission-ui-conventions]] and [[r2s-gcs-design-base-prototype]].
