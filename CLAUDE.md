## Working rules agreed with the user
- Talk to the user in Japanese. Code, comments and commit messages stay in English.
- Never commit `.claude/`, `auto.crt` or `auto.key`. Conventional commits. The user pushes.
- TDD: write the test and watch it fail first. Files ≤400 lines typical (800 max), functions <50 lines, immutable state.
- No `window.confirm`. Lucide icons only, no text glyphs (`src/test/no-glyph-icons.test.ts`).
- `styles/prototype.css` is generated by `scripts/sync-css.py`: never hand-edit it. Never run prettier.
- No vehicle commands or parameter writes unless asked; a mission upload is a write, leave it to the user.
- Do not touch the dev stack's ports: 5760–5793, 8000, 5173, 14550, 14551, 37260. Scratch SITLs use instances 6 / 7.
- No pkill or pattern kills: stop processes by PID.
- SITL home is Kamikochi: 36.2509, 137.6385, 1505, except the QuadPlane at Nachikatsuura: 33.6682026, 135.9041309, 87.36 (`QUADPLANE_HOME`). SITL runs in Docker: `scripts/sitl-docker.sh build`, then `scripts/dev.sh --docker ...`.
- Run Python with `-I`. curl to the API needs `-H 'X-Requested-With: rgcs'` and a login cookie (admin / admin).
- AI tests: no real LLM calls; never log, print or commit API keys. External-data tests: fixtures and a local fake server, no internet.

## Commands
- Rust: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all --check`.
- UI (`apps/rgcs-server/ui`): `npx tsc --noEmit -p tsconfig.app.json`, `npm test -- --run` (add `--testTimeout=30000` under load), `npm run lint`.
- e2e: `scripts/e2e.sh` (own server on :8010, safe next to the dev stack).
- Dev stack: `scripts/dev.sh --docker --sitl 1 --quadplane --plane --rover --siyi-sim --video` → http://127.0.0.1:5173.
